# chain_notes

On-Chain Notebook is a blockchain-based “encrypted notes / permanent proof-of-record notes” application. By combining encrypted storage, decentralized storage, and the immutability of blockchain, it provides users with a secure, private, and permanent environment for creating and preserving their notes.
